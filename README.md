# FocusBoard

A responsive React + Vite task dashboard with task CRUD, search, status/priority filters, calendar, settings, and localStorage persistence.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open the terminal in this folder and run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite.

Tasks and appearance settings are stored in the browser's localStorage.


## Profile greeting
The dashboard displays a time-based greeting with the username saved in Settings. The username is stored in browser localStorage.
